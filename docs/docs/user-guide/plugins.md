# Plugins

Plugins are a powerful way to extend the functionality of your OrganizrX dashboard. They allow you to integrate with other services, add new features, and customize your instance to suit your needs.

## What Plugins Are and How They Work

Plugins in OrganizrX are self-contained modules that provide new features, widgets, and API endpoints. They are written in TypeScript and are designed to be easily installed and configured.

- **Frontend Plugins:** Add new UI components and themes to your dashboard.
- **Backend Plugins:** Add new API endpoints and database functionality.
- **Widget Plugins:** Add new widgets to the homepage.
- **Service Plugins:** Integrate with other services like Plex, Sonarr, and Radarr.

## Installing and Configuring Plugins

To install and configure plugins for your OrganizrX instance, navigate to **Settings > Plugins**.

1. **Find Plugin:** Search for the plugin you want to install in the plugin marketplace.
2. **Install:** Click the install button to download and install the plugin.
3. **Configure:** Provide any required configuration for the plugin (e.g., API keys, URLs).
4. **Enable:** Once configured, you can enable the plugin in the **Settings > Plugins** page.

- **What it shows:** Recently added movies, TV shows, and music.
- **Required URL/API Key:** Obtain this from your Plex developer portal.
- **Configuration Steps:** Provide the URL and API key in the plugin settings.
- **Troubleshooting:** Ensure that your Plex server is accessible from your OrganizrX instance.
