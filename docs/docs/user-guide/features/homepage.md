# Homepage and Widgets

The homepage is the first screen you and your users see in OrganizrX. It provides a customizable at-a-glance view of your entire media ecosystem through a powerful widget system.

## Homepage Widget System

Widgets are self-contained components that provide real-time information and quick access to your favorite services. Each widget is powered by a plugin and can be independently configured.

- **Plex Widget:** View recently added movies, TV shows, and music.
- **Sonarr/Radarr Widgets:** Check upcoming releases, calendar views, and active downloads.
- **Tautulli Widget:** Monitor current playback statistics and server activity.
- **System Health Widget:** See CPU, memory, and disk usage for your host machine.
- **News/RSS Widgets:** Keep up with the latest updates from your favorite sources.

## How Plugins Provide Widgets

Most homepage functionality is provided by plugins. To use a widget, you must first enable and configure the corresponding plugin.

1. Navigate to **Settings > Plugins**.
2. Find the plugin for the service you want to use (e.g., Plex).
3. **Enable:** Click the toggle to activate the plugin.
4. **Configure:** Provide the service URL and API key.
5. **Widget Toggle:** Once configured, you can enable specific widgets offered by the plugin.

## Widget Layout and Customization

OrganizrX gives you full control over how your homepage looks and feels.

1. Go to **Settings > Homepage**.
2. **Layout Grid:** Use the drag-and-drop interface to position widgets where you want them.
3. **Resizing:** Click and drag the corner of a widget to change its width and height on the grid.
4. **Widget Settings:** Click the gear icon on a widget to customize its individual options, such as the number of items to display or the refresh interval.
5. **Mobile Layout:** The grid automatically adjusts for smaller screens, ensuring your homepage remains readable on tablets and phones.

## Advanced Customization

For power users, OrganizrX offers additional ways to tailor the homepage:

- **Custom HTML Widgets:** Add your own code for unique functionality.
- **Weather Widget:** Display local weather information.
- **System Stats:** Monitor multiple servers or services from a single dashboard.

By combining the homepage widget system with our extensive plugin library, you can create a truly personalized command center for your home lab.
