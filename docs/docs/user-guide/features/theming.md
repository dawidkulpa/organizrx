# Theming

OrganizrX is designed to look great on any device, but we also want it to reflect your personal style. Our flexible theming system allows you to customize the look and feel of your dashboard.

## Dark/Light Mode Toggle

OrganizrX includes a built-in dark/light mode toggle. You can choose to use the light theme for daytime and the dark theme for late-night media sessions.

- **System Mode:** The default setting, which automatically matches your operating system or browser preferences.
- **Manual Toggle:** Click the sun/moon icon in the header to switch between light and dark modes.

The light theme provides a clean and crisp interface, while the dark theme is perfect for low-light environments.

## Custom Color Schemes

Beyond the standard dark and light modes, OrganizrX allows you to create custom color schemes.

1. Navigate to **Settings > Appearance**.
2. **Primary Color:** Choose the main color used for buttons, links, and highlights.
3. **Secondary Color:** Choose a color for secondary elements like category headers.
4. **Accent Color:** Select a color for accents and notifications.
5. **Background Color:** (Optional) Customize the background of your dashboard.

Changes are reflected in real-time, allowing you to experiment with different combinations until you find the perfect look.

## CSS Overrides (Advanced)

For users who want even more control, OrganizrX supports custom CSS overrides.

1. Go to **Settings > Appearance > Custom CSS**.
2. **Editor:** Type your own CSS code into the editor.
3. **Preview:** Changes are applied immediately to your dashboard.
4. **Save:** Once you're happy with your changes, click the save button.

This is ideal for advanced users who want to tweak individual elements, change fonts, or create a completely unique look for their OrganizrX instance.

## Custom Icons and Logos

You can further personalize your OrganizrX dashboard by uploading your own icons and logos.

- **Site Logo:** Replace the default OrganizrX logo in the header with your own.
- **Favicon:** Change the icon displayed in the browser tab.
- **Tab Icons:** Provide custom URLs for icons used in your tabs and categories.

Theming in OrganizrX allows you to create a dashboard that is uniquely yours, providing a beautiful and personalized experience for all your users.
